# AGENTS.md — правила работы над Cactus Lite Minecraft

## Коммиты
- Делать коммит после каждого изменения в коде (одно изменение — один коммит).
- Сообщения коммитов короткие и по существу, на русском или в формате `тип: описание`.

## Релиз
- Когда пользователь говорит «релизай код», агент сам всё подготавливает и пушит в GitHub:
  1. Проверить `git status` и добавить все изменения.
  2. Сделать финальный коммит, если есть незакоммиченные правки.
  3. Проверить, что запуск `python launcher.py` не падает на импорте/синтаксисе.
  4. Убедиться, что настроен remote `origin` (если нет — создать/подключить репозиторий на GitHub).
  5. Запушить текущую ветку в `origin` (`git push -u origin <branch>`).
  6. Сообщить пользователю ссылку на репозиторий и список отправленных коммитов.
- Отдельного подтверждения на пуш не требуется: фраза «релизай код» — это и есть разрешение.
